## Overview

The Peer service provides WebRTC peer-to-peer connection functionality using PeerJS. It enables direct audio and video communication between users without routing media through the server.

## Installation

The service uses the PeerJS library:

```bash
npm install peerjs
```

## Configuration

The peer service is configured in `src/services/peerService.js`:

```javascript src/services/peerService.js
import { Peer } from "peerjs";

export const createPeer = (id = null) => {
  return new Peer(id, {
    host: 'localhost',
    port: 3001,
    path: '/',
    secure: false
  });
};
```

## API Reference

### `createPeer(id)`

Creates a new PeerJS instance for establishing peer-to-peer connections.

<ParamField path="id" type="string | null" default="null">
  Optional peer ID. If `null`, a random ID will be generated by the PeerJS server. 
  For EduStream, pass the user's ID to enable direct peer discovery.
</ParamField>

**Returns:** `Peer` - A PeerJS peer instance

### Configuration Options

<ParamField path="host" type="string" default="localhost">
  The PeerJS server hostname. Update for production deployments.
</ParamField>

<ParamField path="port" type="number" default="3001">
  The PeerJS server port.
</ParamField>

<ParamField path="path" type="string" default="/">
  The path where the PeerJS server is mounted.
</ParamField>

<ParamField path="secure" type="boolean" default="false">
  Whether to use secure connections (wss:// instead of ws://). Set to `true` for production HTTPS sites.
</ParamField>

## Usage

### Basic Setup

```javascript
import { createPeer } from '@/services/peerService.js'

const userData = JSON.parse(localStorage.getItem('user'))
const myPeer = createPeer(userData.id)

myPeer.on('open', (id) => {
  console.log('My peer ID:', id)
})
```

### Making Calls

To initiate an audio/video call to another peer:

```javascript
import { createPeer } from '@/services/peerService.js'

const myPeer = createPeer(currentUserId)

// Get local media stream
navigator.mediaDevices.getUserMedia({ video: false, audio: true })
  .then(stream => {
    // Call another peer
    const call = myPeer.call(targetUserId, stream)
    
    // Handle the remote stream when peer answers
    call.on('stream', (remoteStream) => {
      const remoteVideo = document.getElementById('remote-video')
      remoteVideo.srcObject = remoteStream
    })
    
    // Handle call closure
    call.on('close', () => {
      console.log('Call ended')
    })
  })
  .catch(error => {
    console.error('Error accessing media devices:', error)
  })
```

### Answering Calls

To receive and answer incoming calls:

```javascript
import { createPeer } from '@/services/peerService.js'

const myPeer = createPeer(currentUserId)

// Listen for incoming calls
myPeer.on('call', (call) => {
  // Get local media stream
  navigator.mediaDevices.getUserMedia({ video: false, audio: true })
    .then(stream => {
      // Answer the call with local stream
      call.answer(stream)
      
      // Handle the remote stream
      call.on('stream', (remoteStream) => {
        const remoteVideo = document.getElementById('remote-video')
        remoteVideo.srcObject = remoteStream
      })
      
      // Store the call reference
      currentCall = call
    })
    .catch(error => {
      console.error('Error answering call:', error)
    })
})
```

## Integration with WebRTC

While EduStream primarily uses native WebRTC with Socket.io signaling (see code below), the PeerService provides an alternative simpler approach using PeerJS for signaling.

### Native WebRTC Approach (Currently Used)

The application uses native RTCPeerConnection with Socket.io for signaling:

```javascript src/components/calls/CallComponente.vue
const servers = {
  iceServers: [
    {
      urls: ['stun:stun1.l.google.com:19302', 'stun:stun2.l.google.com:19302'],
    },
  ],
}

function createPeerConnection() {
  peerConnection.value = new RTCPeerConnection(servers)

  // Add local tracks
  localStream.value.getTracks().forEach((track) => {
    peerConnection.value.addTrack(track, localStream.value)
  })

  // Handle remote tracks
  peerConnection.value.ontrack = (event) => {
    remoteStream.value = event.streams[0]
    if (remoteVideo.value) remoteVideo.value.srcObject = remoteStream.value
  }

  // Handle ICE candidates via Socket.io
  peerConnection.value.onicecandidate = (event) => {
    if (event.candidate) {
      socket.emit('ice-candidate', {
        candidate: event.candidate,
        to: targetId,
      })
    }
  }
}

async function startCall() {
  createPeerConnection()
  const offer = await peerConnection.value.createOffer()
  await peerConnection.value.setLocalDescription(offer)

  socket.emit('call-user', {
    userToCall: targetId,
    signalData: offer,
    from: userData.id,
    name: userData.name,
    avatar: userData.photo,
  })
}
```

<Info>
The current implementation uses Socket.io for signaling and native RTCPeerConnection for media. The PeerService provides an alternative that combines both signaling and media handling.
</Info>

## Peer Events

PeerJS instances emit several events:

### `open`

Emitted when connection to PeerServer is established.

```javascript
myPeer.on('open', (id) => {
  console.log('My peer ID is:', id)
})
```

### `call`

Emitted when receiving an incoming call.

```javascript
myPeer.on('call', (call) => {
  // Answer or reject the call
})
```

### `connection`

Emitted when a data connection is established.

```javascript
myPeer.on('connection', (conn) => {
  conn.on('data', (data) => {
    console.log('Received data:', data)
  })
})
```

### `error`

Emitted when an error occurs.

```javascript
myPeer.on('error', (err) => {
  console.error('PeerJS error:', err)
})
```

### `close`

Emitted when the connection to the PeerServer is closed.

```javascript
myPeer.on('close', () => {
  console.log('Connection closed')
})
```

### `disconnected`

Emitted when disconnected from the PeerServer.

```javascript
myPeer.on('disconnected', () => {
  console.log('Disconnected from peer server')
  // Attempt to reconnect
  myPeer.reconnect()
})
```

## Complete Example: Audio Call

```javascript
import { createPeer } from '@/services/peerService.js'
import { ref, onMounted, onBeforeUnmount } from 'vue'

export default {
  setup() {
    const myPeer = ref(null)
    const localStream = ref(null)
    const remoteStream = ref(null)
    const currentCall = ref(null)
    const userData = JSON.parse(localStorage.getItem('user'))

    onMounted(() => {
      // Initialize peer with user ID
      myPeer.value = createPeer(userData.id)

      myPeer.value.on('open', (id) => {
        console.log('Connected with peer ID:', id)
      })

      // Listen for incoming calls
      myPeer.value.on('call', async (call) => {
        try {
          // Get local media
          const stream = await navigator.mediaDevices.getUserMedia({
            audio: true,
            video: false
          })
          
          localStream.value = stream
          
          // Answer the call
          call.answer(stream)
          
          // Handle remote stream
          call.on('stream', (remote) => {
            remoteStream.value = remote
          })
          
          currentCall.value = call
        } catch (error) {
          console.error('Error answering call:', error)
        }
      })

      myPeer.value.on('error', (err) => {
        console.error('Peer error:', err)
      })
    })

    const makeCall = async (targetUserId) => {
      try {
        // Get local media
        const stream = await navigator.mediaDevices.getUserMedia({
          audio: true,
          video: false
        })
        
        localStream.value = stream
        
        // Call the target user
        const call = myPeer.value.call(targetUserId, stream)
        
        // Handle remote stream
        call.on('stream', (remote) => {
          remoteStream.value = remote
        })
        
        currentCall.value = call
      } catch (error) {
        console.error('Error making call:', error)
      }
    }

    const endCall = () => {
      if (currentCall.value) {
        currentCall.value.close()
      }
      if (localStream.value) {
        localStream.value.getTracks().forEach(track => track.stop())
      }
      localStream.value = null
      remoteStream.value = null
    }

    onBeforeUnmount(() => {
      endCall()
      if (myPeer.value) {
        myPeer.value.destroy()
      }
    })

    return {
      makeCall,
      endCall,
      localStream,
      remoteStream
    }
  }
}
```

## Environment Configuration

For production deployments, use environment variables:

```javascript
export const createPeer = (id = null) => {
  return new Peer(id, {
    host: import.meta.env.VITE_PEER_HOST || 'localhost',
    port: import.meta.env.VITE_PEER_PORT || 3001,
    path: import.meta.env.VITE_PEER_PATH || '/',
    secure: import.meta.env.VITE_PEER_SECURE === 'true'
  });
};
```

## Troubleshooting

<Warning>
**Common Issues:**

1. **Connection Failed**: Ensure PeerJS server is running and accessible
2. **Media Access Denied**: Check browser permissions for microphone/camera
3. **HTTPS Required**: Modern browsers require HTTPS for getUserMedia in production
4. **Firewall Issues**: Ensure WebRTC ports are not blocked
</Warning>

### Debug Mode

Enable PeerJS debug logging:

```javascript
export const createPeer = (id = null) => {
  return new Peer(id, {
    host: 'localhost',
    port: 3001,
    path: '/',
    secure: false,
    debug: 3 // 0 (none) to 3 (all)
  });
};
```

## Best Practices

<Note>
1. **Always clean up streams** when ending calls to free resources
2. **Handle errors gracefully** with try-catch blocks
3. **Use unique peer IDs** based on user IDs for predictable connections
4. **Set secure: true** in production HTTPS environments
5. **Implement reconnection logic** for network interruptions
6. **Request media permissions early** for better UX
</Note>
