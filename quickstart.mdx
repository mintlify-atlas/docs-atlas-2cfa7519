## Get Started

<Steps>
  <Step title="Access the Application">
    Open your browser and navigate to:
    
    ```bash
    http://localhost:5173
    ```
    
    You should see the EduStream landing page with options to sign in or create an account.
  </Step>

  <Step title="Create an Account or Sign In">
    If you're a first-time user, create an account with your email and password. If you already have an account, sign in.
    
    The authentication system uses JWT tokens for secure session management:
    
    ```javascript src/views/Login.vue
    // Login authentication flow
    const login = async () => {
      try {
        const response = await axios.post('/login', {
          email: user.email,
          password: user.password
        });
        
        if (response.data.success) {
          localStorage.setItem('token', response.data.token);
          localStorage.setItem('user', JSON.stringify(response.data.user));
          router.push('/dashboard/statistics');
        }
      } catch (error) {
        console.error('Login failed:', error);
      }
    };
    ```
    
    <Note>
    Your authentication token is stored securely in localStorage and automatically included in all API requests.
    </Note>
  </Step>

  <Step title="Explore the Dashboard">
    After logging in, you'll be directed to the main dashboard at `/dashboard/statistics`.
    
    The dashboard displays:
    - **Active Users**: Currently online users
    - **Live Streams**: Ongoing broadcasts
    - **Messages**: Total messages sent
    - **Groups**: Number of active groups
    - **Activity Chart**: Hourly usage statistics
    
    From here, you can access all major features through the sidebar navigation.
  </Step>

  <Step title="Start a Real-time Chat">
    Navigate to **Chats** from the sidebar to access the messaging interface.
    
    The chat system uses Socket.io for real-time communication:
    
    ```javascript src/services/socket.js
    import { io } from 'socket.io-client'

    const socket = io('http://localhost:3001', {
      autoConnect: true,
    })

    export default socket
    ```
    
    Select a user or group to start chatting. Messages are delivered instantly to all connected participants.
  </Step>

  <Step title="Make a Video Call">
    To initiate a video call:
    
    1. Navigate to the **Users** section
    2. Select a user you want to call
    3. Click the call button to start
    
    EduStream uses PeerJS and WebRTC for peer-to-peer video/audio connections:
    
    ```javascript src/services/peerService.js
    import { Peer } from "peerjs";

    export const createPeer = (id = null) => {
      return new Peer(id, {
        host: 'localhost',
        port: 3001,
        path: '/',
        secure: false
      });
    };
    ```
    
    The call interface provides controls for:
    - Muting/unmuting audio
    - Ending the call
    - Minimizing the call window for multitasking
    
    <Tip>
    You can minimize an active call to continue working while staying connected. The mini call component remains visible in the corner.
    </Tip>
  </Step>

  <Step title="Host Your First Stream">
    To start a live broadcast:
    
    1. Navigate to **Transmissions** from the sidebar
    2. Click **Create New Stream** or **Start Broadcast**
    3. Configure your stream settings (title, description)
    4. Click **Go Live**
    
    As a host, you can:
    - **Manage Participants**: Admit or reject viewers from the waiting room
    - **Control Media**: Toggle camera, microphone, and screen sharing
    - **Record**: Save your stream using the integrated recording feature
    - **Monitor**: View all active participants and their connection status
    
    ```javascript src/router/index.ts
    {
      path: '/liveHost/:id',
      name: 'live',
      component: Live,
    }
    ```
    
    Your stream is accessible at a unique URL that viewers can use to join.
  </Step>

  <Step title="Join a Stream as a Viewer">
    To watch a live stream:
    
    1. Find available streams on the **Dashboard** or receive an invitation link
    2. Click to join the stream
    3. Wait for the host to admit you from the waiting room
    4. Once admitted, you can watch, interact in chat, and optionally share your camera/audio
    
    ```javascript src/router/index.ts
    {
      path: '/liveViewer/:link/:id',
      name: 'live-viewer',
      component: LiveViewer,
    }
    ```
    
    <Info>
    Viewers can request to enable their camera/microphone to participate in the stream. The host must approve these requests.
    </Info>
  </Step>
</Steps>

## Common Issues

<AccordionGroup>
  <Accordion title="WebRTC Connection Failed">
    If video calls or streaming fail to connect:
    
    - Ensure the PeerJS server is running on port 3001
    - Check that your browser allows camera/microphone access
    - Verify firewall settings aren't blocking WebRTC connections
    - Try using a different browser (Chrome and Firefox work best)
  </Accordion>

  <Accordion title="Chat Messages Not Appearing">
    If real-time chat isn't working:
    
    - Verify the Socket.io server is running on port 3001
    - Check the browser console for connection errors
    - Ensure your authentication token is valid
    - Refresh the page to re-establish the Socket.io connection
  </Accordion>

  <Accordion title="Stream Won't Start">
    If you can't start a stream:
    
    - Grant browser permissions for camera and microphone
    - Check that no other application is using your camera
    - Verify the backend services are running
    - Clear browser cache and restart the application
  </Accordion>

  <Accordion title="User Not Admitted to Stream">
    If viewers can't join your stream:
    
    - As a host, check the waiting room panel for pending users
    - Click the green checkmark to admit users
    - Ensure the stream URL is correct and the stream is active
  </Accordion>
</AccordionGroup>
