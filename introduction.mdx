## Built With Modern Technology

EduStream leverages cutting-edge web technologies to deliver a robust platform:

- **Vue.js 3** - Progressive JavaScript framework with Composition API
- **Socket.io** - Real-time bidirectional event-based communication
- **PeerJS** - WebRTC peer-to-peer data, video, and audio calls
- **Pinia** - Intuitive state management for Vue
- **Tailwind CSS** - Utility-first CSS framework for beautiful UI
- **HLS.js** - HTTP Live Streaming for video playback

## Platform Architecture

<Info>
EduStream follows a modern SaaS architecture with separate client and server components, designed for scalability and real-time performance.
</Info>

The platform consists of:

- **Frontend Application** - Vue 3 single-page application with routing and state management
- **Real-time Services** - Socket.io for instant messaging and event broadcasting
- **WebRTC Layer** - Peer-to-peer connections for high-quality video/audio
- **User Management** - Authentication, profiles, and permission systems
