## Overview

EduStream is a modern video streaming and communication platform built with Vue 3 and a carefully selected set of modern web technologies. The application supports real-time video calls, live streaming, chat functionality, and comprehensive user management.

## Project Structure

The source code is organized following Vue 3 best practices:

```bash
src/
├── assets/          # Static assets (images, styles)
├── components/      # Reusable Vue components
│   ├── Settings/    # Settings-related components
│   ├── calls/       # Call interface components
│   └── dialogs/     # Modal dialogs
├── layouts/         # Layout components
├── router/          # Vue Router configuration
├── services/        # API and external services
├── stores/          # Pinia state management
└── views/           # Page-level components
```

<Note>
  The project uses the `@` alias to reference the `src/` directory, configured in `vite.config.ts`.
</Note>

## Application Bootstrap

The application initializes in `src/main.ts`:

```typescript src/main.ts
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import router from './router'
import './index.css'
import App from './App.vue'

const app = createApp(App)

app.use(createPinia())
app.use(router)
app.mount('#app')
```

### Initialization Order

1. **Create Vue App**: Initialize the root Vue instance
2. **Install Pinia**: Set up state management
3. **Install Router**: Configure navigation
4. **Mount App**: Attach to DOM element `#app`

<Info>
  Pinia is installed before the router to ensure stores are available for route guards and components.
</Info>

## Build Configuration

EduStream uses Vite for lightning-fast development and optimized production builds:

```typescript vite.config.ts
import { fileURLToPath, URL } from 'node:url'
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [
    vue(),
  ],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    },
  },
})
```

## Architecture Patterns

### Component Organization

- **Views**: Page-level components mapped to routes
- **Components**: Reusable UI components
- **Layouts**: Wrapper components for consistent page structure

### Data Flow

1. User interactions trigger component methods
2. Components dispatch actions to Pinia stores
3. Stores update reactive state
4. Components re-render with updated data

### Communication Layer

The application uses multiple communication protocols:

- **HTTP/REST**: API calls via Axios
- **WebRTC**: Peer-to-peer video/audio via PeerJS and LiveKit
- **WebSocket**: Real-time messaging via Socket.io
- **HLS**: Video streaming playback
