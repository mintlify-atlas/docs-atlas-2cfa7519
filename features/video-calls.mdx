## Overview

EduStream's video call system enables direct peer-to-peer communication between users using WebRTC technology. The system supports audio-only and video calls with real-time connection management.

## Initiating a Call

### Outgoing Calls

When a user initiates a call, the system creates a WebRTC connection:

```javascript
// From CallComponente.vue:324
async function startCall() {
  createPeerConnection()
  const offer = await peerConnection.value.createOffer()
  await peerConnection.value.setLocalDescription(offer)
  
  const userData = JSON.parse(localStorage.getItem('user'))
  
  socket.emit('call-user', {
    userToCall: targetId,
    signalData: offer,
    from: userData.id,
    name: userData.name,
    avatar: userData.photo
  })
}
```

<Steps>
  <Step title="Setup Local Media">
    The system requests access to the user's microphone:
    
    ```javascript
    // From CallComponente.vue:280
    async function setupLocalMedia() {
      try {
        localStream.value = await navigator.mediaDevices.getUserMedia({ 
          video: false, 
          audio: true 
        })
        if (localVideo.value) localVideo.value.srcObject = localStream.value
        
        // Sync with call store
        callStore.setStreams(localStream.value, null)
      } catch (error) {
        console.error('Error accessing media', error)
        addToast('No se pudo acceder a la cámara/micrófono', 'error')
      }
    }
    ```
  </Step>
  
  <Step title="Create Peer Connection">
    WebRTC peer connection is established with STUN servers:
    
    ```javascript
    // From CallComponente.vue:293
    function createPeerConnection() {
      peerConnection.value = new RTCPeerConnection(servers)
      
      // Add local tracks
      localStream.value.getTracks().forEach((track) => {
        peerConnection.value.addTrack(track, localStream.value)
      })
      
      // Handle remote tracks
      peerConnection.value.ontrack = (event) => {
        remoteStream.value = event.streams[0]
        if (remoteVideo.value) remoteVideo.value.srcObject = remoteStream.value
        callStore.setStreams(localStream.value, remoteStream.value)
      }
      
      // Handle ICE candidates
      peerConnection.value.onicecandidate = (event) => {
        if (event.candidate) {
          socket.emit('ice-candidate', {
            candidate: event.candidate,
            to: targetId
          })
        }
      }
    }
    ```
  </Step>
  
  <Step title="Wait for Answer">
    The system shows a "calling" UI while waiting for the recipient to answer.
  </Step>
</Steps>

### Answering a Call

When the recipient accepts:

```javascript
// From CallComponente.vue:340
async function handleReceiveCall(offerSignal) {
  createPeerConnection()
  await peerConnection.value.setRemoteDescription(
    new RTCSessionDescription(offerSignal)
  )
  const answer = await peerConnection.value.createAnswer()
  await peerConnection.value.setLocalDescription(answer)
  
  socket.emit('make-answer', {
    signal: answer,
    to: targetId
  })
}
```

## Call Timer

The system tracks call duration in real-time:

```javascript
// From CallComponente.vue:378
function startTimer() {
  timerInterval.value = setInterval(() => {
    callDuration.value++
    callStore.updateCallDuration(callDuration.value)
  }, 1000)
}

function formatTime(seconds) {
  const mins = Math.floor(seconds / 60)
  const secs = seconds % 60
  return `${mins.toString().padStart(2, '0')}:${secs.toString().padStart(2, '0')}`
}
```

## Ending a Call

Calls can be terminated by either party:

```javascript
// From CallComponente.vue:364
function endCall(emitEvent = true) {
  if (emitEvent && socket) {
    socket.emit('end-call', { to: targetId })
  }
  callStore.endCall()
  router.go(-1) // Go back
}
```

<Steps>
  <Step title="Emit End Event">
    Notify the other party that the call is ending
  </Step>
  
  <Step title="Stop Media Tracks">

  <Step title="Close Peer Connection">
    Terminate the WebRTC connection
  </Step>
  
  <Step title="Clean Up State">
    Clear call store and return to previous view
  </Step>
</Steps>

## Socket Events

### Signaling Events

| Event | Direction | Purpose |
|-------|-----------|----------|
| `call-user` | Caller → Server | Initiate call with offer |
| `incoming-call` | Server → Callee | Notify of incoming call |
| `make-answer` | Callee → Server | Send answer signal |
| `call-answered` | Server → Caller | Deliver answer signal |
| `ice-candidate` | Both → Server | Exchange ICE candidates |
| `call-rejected` | Callee → Server | Reject incoming call |
| `end-call` | Either → Server | Terminate call |
| `call-ended` | Server → Other | Notify of call termination |

### Socket Listeners

```javascript
// From CallComponente.vue:232-258
socket.on('call-answered', async (data) => {
  if (callState.value === 'calling') {
    callState.value = 'connected'
    await peerConnection.value.setRemoteDescription(
      new RTCSessionDescription(data.signal)
    )
    startTimer()
  }
})

socket.on('ice-candidate', async (data) => {
  if (peerConnection.value) {
    await peerConnection.value.addIceCandidate(
      new RTCIceCandidate(data.candidate)
    )
  }
})

socket.on('call-rejected', () => {
  router.push({ name: 'chats' })
})

socket.on('call-ended', () => {
  endCall(false) // Don't emit hangup again
})
```

## Error Handling

### Media Access Errors

```javascript
// Handle various permission and device errors
try {
  localStream.value = await navigator.mediaDevices.getUserMedia({
    video: false,
    audio: true
  })
} catch (error) {
  if (error.name === 'NotAllowedError') {
    addToast('Permiso denegado para acceder al micrófono', 'error')
  } else if (error.name === 'NotFoundError') {
    addToast('No se encontró micrófono', 'error')
  } else if (error.name === 'NotReadableError') {
    addToast('El micrófono está siendo usado por otra aplicación', 'error')
  }
}
```
