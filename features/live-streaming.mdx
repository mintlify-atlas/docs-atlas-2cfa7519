## Overview

EduStream's live streaming feature enables educators to broadcast real-time video sessions to multiple participants. Hosts can share their screen, manage participants, record sessions, and interact through integrated chat.

## Host Features

### Starting a Live Stream

Hosts can initiate a live stream with full control over participants and content sharing:

<Steps>
  <Step title="Initialize Stream">
    The stream starts by setting up WebRTC peer connections and requesting media permissions.
    
    ```javascript
    // From LiveHost.vue:862
    async startMeeting() {
      // Request camera and microphone access
      this.localStream = await navigator.mediaDevices.getUserMedia({
        video: {
          width: { ideal: 640, max: 640 },
          height: { ideal: 480, max: 480 },
          frameRate: { ideal: 15, max: 30 }
        },
        audio: {
          echoCancellation: true,
          noiseSuppression: true,
          autoGainControl: true
        }
      })
    }
    ```
  </Step>
  
  <Step title="Create Peer Connection">
    A PeerJS connection is established to handle WebRTC connections:
    
    ```javascript
    // From LiveHost.vue:905
    this.peer = new Peer(undefined, {
      host: 'localhost',
      port: 3001,
      path: '/peerjs',
      debug: 3
    })
    ```
  </Step>
  
  <Step title="Update Stream Status">
    The transmission status is updated in the database:
    
    ```javascript
    // From LiveHost.vue:785
    await api.put(`/transmissions/${this.roomId}/status`, { status: 1 })
    ```
  </Step>
</Steps>

### Screen Sharing

Hosts can share their screen with all participants:

```javascript
// From LiveHost.vue:1049
async startScreenShare() {
  this.screenStream = await navigator.mediaDevices.getDisplayMedia({
    video: true,
    audio: false
  })
  
  const screenTrack = this.screenStream.getVideoTracks()[0]
  this.pantallaAct = true
  
  // Replace video track for all viewers
  await this.replaceVideoTrackForAll(screenTrack)
  
  // Handle when user stops sharing
  screenTrack.onended = () => {
    this.stopScreenShare()
  }
}
```

<Note>
When screen sharing is active, the host's camera feed appears as a small picture-in-picture overlay in the bottom right corner.
</Note>

### Recording

Streams can be recorded and uploaded to api.video:

<Steps>
  <Step title="Start Recording">
    Recording captures the shared screen or camera:
    
    ```javascript
    // From LiveHost.vue:1393
    async startRecording() {
      // Get upload token
      const token = await this.getUploadToken()
      
      // Setup MediaRecorder
      const mimeType = this.getSupportedMimeType()
      this.mediaRecorder = new MediaRecorder(this.screenStream, { mimeType })
      
      this.mediaRecorder.ondataavailable = (event) => {
        if (event.data.size > 0) {
          this.recordedChunks.push(event.data)
        }
      }
      
      this.mediaRecorder.start(1000)
      this.isRecording = true
    }
    ```
  </Step>
  
  <Step title="Upload to api.video">
    When recording stops, the video is uploaded:
    
    ```javascript
    // From LiveHost.vue:1458
    async uploadToApiVideo() {
      const blob = new Blob(this.recordedChunks, { type: mimeType })
      const formData = new FormData()
      formData.append('file', blob, `reunion-${this.roomId}-${Date.now()}.webm`)
      
      const response = await axios.post(
        `https://ws.api.video/upload?token=${this.uploadToken}`,
        formData,
        {
          onUploadProgress: (progressEvent) => {
            const percentCompleted = Math.round(
              (progressEvent.loaded * 100) / progressEvent.total
            )
            this.uploadProgress = percentCompleted
          }
        }
      )
    }
    ```
  </Step>
</Steps>

<Warning>
Recording automatically stops if the user stops screen sharing. The recording link is saved to the transmission record when the stream ends.
</Warning>

## Stream Timing

All participants see synchronized stream duration:

```javascript
// From LiveHost.vue:1213
iniciarContador() {
  const startMs = this.startTime < 10000000000 
    ? this.startTime * 1000 
    : this.startTime
  
  this.intervalo = setInterval(() => {
    const ahora = Date.now()
    const diffInMs = ahora - startMs
    const segundosTranscurridos = Math.floor(diffInMs / 1000)
    this.tiempo = segundosTranscurridos > 0 ? segundosTranscurridos : 0
```

## Technical Architecture

### WebRTC Configuration

EduStream uses PeerJS for WebRTC connections:

```javascript
// Peer server configuration
const peer = new Peer(undefined, {
  host: 'localhost',
  port: 3001,
  path: '/peerjs',
  debug: 3
})
```

### Socket Events

| Event | Direction | Purpose |
|-------|-----------|----------|
| `start-stream` | Host → Server | Initialize stream |
| `pending-request` | Server → Host | Viewer join request |
| `response-request` | Host → Server | Admit/reject viewer |
| `left-room` | Server → Host | Viewer disconnected |
| `end-stream` | Host → Server | Terminate stream |
| `expel-viewer` | Host → Server | Remove participant |
